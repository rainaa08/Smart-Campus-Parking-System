# Smart-Campus-Parking-System
A menu-driven parking management program written in C. It manages a campus parking lot with 10 slots, records vehicle entry and exit, calculates parking fees, and shows live availability

Instructions to Compile and Execute the Program Program Name: Smart Campus Parking System Programming Language: C File Name: parking.c Steps to Compile and Execute Step 1: Open the C Compiler Open any C programming environment, such as GCC, Code::Blocks, Dev-C++, or an online C compiler. Step 2: Create a New File Create a new C source file and name it parking.c. Step 3: Write the Code Copy the complete Smart Campus Parking System code into the file. Step 4: Save the Program Save the file with the .c extension. Step 5: Compile the Program If using GCC, open the terminal in the folder containing the file and enter: gcc parking.c -o parking This compiles the C program and generates an executable file. Step 6: Execute the Program On Windows: .\parking.exe On Linux or macOS: ./parking Step 7: Select a Menu Option After successful execution, the following menu appears:
